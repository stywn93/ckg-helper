CKG No Worry saat ini mampu menjalankan :

- CKG Umum - Pelayanan Anak
- CKG Umum - Pelayanan Remaja
- CKG Umum - Pelayanan Dewasa
- CKG Umum - Pelayanan Lansia
- CKG Sekolah - Pendaftaran Baru
- CKG Sekolah - Konfirmasi Kehadiran
